¿Para qué reducir las variables?

Algunas variables numéricas contienen información relacionada. Por ejemplo, el valor de los productos y el precio máximo pueden variar conjuntamente. PCA construye nuevas variables, denominadas componentes principales, a partir de combinaciones de las anteriores. La primera componente recoge la mayor variación disponible; las siguientes agregan información sin repetir la dirección de las anteriores.

Antes de aplicar PCA se deben completar los faltantes y estandarizar las variables numéricas. Ambas transformaciones se ajustan con entrenamiento para evitar que información del conjunto de validación intervenga en la construcción del modelo. La descomposición en valores singulares, conocida como SVD, es una de las herramientas matemáticas con las que puede calcularse PCA.

En el laboratorio se conservará el número mínimo de componentes que explique al menos el 90 % de la varianza de las variables numéricas. Este umbral es una decisión de trabajo, no una garantía de obtener una mejor clasificación. Las cuatro variables categóricas mantienen su preparación por separado.

¿Qué debe comprobarse?

El cuaderno produce una curva de varianza acumulada. A partir de ella se debe informar cuántas variables numéricas se utilizaron inicialmente, cuántas componentes se conservaron y qué información podría perderse al comprimirlas.

Para saber si existe alguna mejora se necesita un punto de referencia. Los cuatro modelos usan la misma muestra, la misma partición y el mismo umbral de clasificación de 0,50. Solo cambian la reducción de dimensionalidad y la fuerza de la regularización.

En regresión logística, el parámetro C controla de forma inversa la regularización. Un valor menor corresponde a una penalización más fuerte. Para este ejercicio se usa class_weight='balanced' en las cuatro alternativas.

Además de Accuracy, se deben contrastar Precision, Recall, F1 y Average Precision. Dos modelos pueden obtener una Accuracy similar y cometer errores empresariales muy diferentes. Se retoma el supuesto didáctico de la semana 12: cada falso positivo cuesta R$ 8 y cada falso negativo cuesta R$ 35. Estas cifras no son costos observados de Olist.

¿Las particiones se comportan de manera similar?

La prueba de Kolmogorov-Smirnov para dos muestras permite contrastar las distribuciones de una variable continua en dos grupos. Se utilizará para comparar valor_flete entre entrenamiento y validación. La hipótesis nula establece que ambas muestras proceden de la misma distribución; la alternativa plantea que sus distribuciones son diferentes.

from scipy.stats import ks_2samp

resultado = ks_2samp(train['valor_flete'].dropna(),
                     valid['valor_flete'].dropna())
print(resultado.statistic, resultado.pvalue)

La interpretación deberá indicar el estadístico D, el valor p y la decisión al nivel de significancia del 5 %. No rechazar la hipótesis nula no demuestra que las distribuciones sean idénticas. Del mismo modo, esta prueba no compara directamente el desempeño de los modelos ni permite afirmar que una configuración es estadísticamente superior a otra.
